# FEP 2026 — Engenharia de Prompt na era dos agentes

O FEP original (2025) reescrito técnica por técnica para os modelos de setembro de 2026: o que morreu, o que só serve em certas condições, o que continua e o que faltava.

- `PLANO-FEP2026.md` — diagnóstico do FEP original, triagem em quatro baldes (morreu / só quando serve / continua / novo), tabela de-para dos 47 tópicos e o esqueleto do curso novo (1 trilha, 6 módulos).
